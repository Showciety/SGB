# Coordinator Guide

Your role as a SGB coordinator, in a nutshell, is to help transition the event between time slots. You have two goals:
1. Make sure the streamer in the next time slot (next streamer) is ready and knows when the raid is coming.
2. Make sure the streamer in the previous time slot (previous streamer) raids on time and prepares the audience for the next stream.

These checklists don't necessarily need to be done in order except for saying hi before coordinating both streamers with an iron fist :)

## Next Streamer Checklist
Things to check for the next streamer before coordinating with the previous streamer. Please try to help as much as you can, but you are not responsible for fixing any issues - only making the streamer aware of them.
- [ ] Say hi to the next streamer :)
- [ ] Check everything in the overlay looks correct
- [ ] Check stream audio (e.g. not muted, game audio present, game audio volume vs mic audio volume, alert audio levels, etc...)
- [ ] Check stream audio in the VOD or a clip (e.g. make sure some audio such as mic, game, alerts, etc... isn't accidentally not being sent to the VOD)
- [ ] Ensure all required [Bot Commands](https://www.github.com/Showciety/SGB/blob/main/README.md#bot-commands) are active and return the correct text / links
- [ ] Make sure there are no panels or chat commands related to "donate" or "charity" that do not go to the donate page for the event - "tip" is fine
- [ ] Make sure the streamer has the "Charity" Twitch tag
- [ ] If the streamer wants to you can quiz them on the [Talking Points](https://www.github.com/Showciety/SGB/blob/main/README.md#talking-points) to make sure they remember them correctly! (OPTIONAL)

## Previous Streamer Checklist
Mostly just make sure they are going to raid out on time. Unless there is a dire emergency please ensure that things run as per the schedule.
- [ ] Say hi to the previous streamer :)
- [ ] Ensure they are aware when the next streamer is ready
- [ ] Ensure they are aware when their time slot ends
- [ ] Ensure they know who they are raiding and have the correct spelling (i.e. look at raid popup to verify spelling and correct them if it's wrong)
